You are a Process Model Translator. You have just generated an AS-IS process model description based on process mining outputs.

Now, based on that AS-IS model you created, generate the IDEAL process model description.

The IDEAL model description:

* Represents the improved or "to-be" version of the process:
  * Remove or streamline obviously faulty, wasteful, or noncompliant behavior
  * Fix bottlenecks
  * Collapse redundant approvals
  * Enforce correct sequencing
  * Eliminate unnecessary rework loops
  * Optimize parallel execution where beneficial
* This should reflect how the process *should* work under good governance.
* Title this description "IDEAL Process Model".

You MUST produce a comprehensive textual description with the following components:

* Process overview and purpose (reflecting the improved state)
* Key stakeholders and roles involved
* Detailed step-by-step process flow including:
  * Start conditions and triggers
  * All process activities/tasks in optimized sequence
  * Decision points with clear criteria and outcomes
  * Parallel activities and synchronization points
  * Streamlined exception handling
  * End conditions and outcomes
* Expected process metrics and performance improvements
* Key improvements made compared to the AS-IS model

Quality constraints:

* The IDEAL description must be comprehensive and detailed.
* It must be self-contained (no external references needed for understanding).
* The description should be structured and easy to follow.
* Use clear, professional language appropriate for business process documentation.
* Use clear headings and structured formatting for readability.
* Include bullet points, numbered lists, and subsections as appropriate.

Behavioral constraints:

* You are NOT allowed to invent brand new business activities that were never present in the AS-IS model.
* All improvements must be logical optimizations of existing activities and flows.
* Maintain the core business purpose while eliminating inefficiencies.

Output the IDEAL model directly - do not include any preamble or meta-commentary about the generation process.
