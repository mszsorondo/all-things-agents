IDEAL Process Model

Process overview and purpose
- Purpose: A sound and governable loan origination process from appointment request through underwriting decision, minimizing dead-ends, clarifying decision logic, and ensuring only necessary steps are performed.
- Design principles applied:
  • Remove deadlock-prone/unsound behavior.
  • Make co-signer involvement conditional based on need.
  • Ensure submission is possible when prerequisites are met.
  • Place the collateral visit task where it adds value and is governed.
  • Treat 'skipped_examination' as a data condition, not a control-flow step.

Key stakeholders and roles involved
- Roles are not specified in the source; responsibilities are described at the activity level without lane assignments.

Detailed step-by-step process flow
Start conditions and triggers
- Start event: Request Appointment.

Activities and sequence
1) Request Appointment (start)
   - Decision: Appointment approved?
     • No → Appointment Denied → End.
     • Yes → Set Appointment.

2) Set Appointment
   - Then Hand In Credit Appliaction [sic].
   - Then Verify Borrowers Information.

3) Verify Borrowers Information
   - Decision: Verification outcome
     • Fail → Application Rejected → End.
     • Pass → Proceed to risk/credit sufficiency evaluation.

4) Conditional co-signer decision (explicit XOR)
   - Is a co-signer required based on credit policy?
     • Yes → Request Co-Signer On Loan (obtain co-signer details/commitment).
     • No → Skip co-signer step.
   - After this decision (regardless of path), converge and proceed.

5) Submit File to Underwriter
   - Submission is permitted as soon as:
     • Verification has passed, and
     • If required, the co-signer has been requested/obtained.
   - The model removes the discovered artifact that made the co-signer step mandatory in all cases.

   - Optional activity: Make Visit to Assess Colatteral
