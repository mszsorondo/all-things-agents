"IDEAL Process Model

Process overview and purpose
- Purpose: A controlled, efficient, and auditable hiring workflow from application to a definitive conclusion, minimizing unnecessary checks and rework while preserving all essential decision points.
- Design principles:
  - Gate expensive checks until candidate viability is established.
  - Enforce clear gateway logic (exclusive vs inclusive) with explicit synchronization.
  - Eliminate irregular state reversals and unbounded loops.
  - Keep activities identical to the discovered set; improve sequencing and control-flow only.

Key stakeholders and roles involved
- Roles were not specified in the source; the model defines responsibility as process steps without swimlane assignments.

Detailed step-by-step process flow
1) Start conditions and trigger
- Start: Hand In Job Application.
- Decision G1 (exclusive):
  - If basic criteria are not met: Application Rejected (terminal).
  - Else: proceed to Telephonic Screening.

2) Telephonic Screening
- Decision G2 (exclusive):
  - If not suitable after telephonic: Application Rejected (terminal).
  - Else: proceed to Screening Interview.
- Rationale: Remove unsynchronized parallelization at this point to streamline and avoid premature background checks.

3) Screening Interview
- Decision G3 (exclusive):
  - If not suitable: Application Rejected (terminal).
  - Else: proceed to Coding Interview.
- Rationale: Technical assessment should follow only for candidates who pass initial screening.

4) Coding Interview
- Decision G4 (exclusive routing to specialization):
  - Route the candidate to exactly one specialized technical interview track aligned with the requisition: Frontend Interview OR ML Interview OR Backend Interview.
  - Exception (controlled inclusive): If the requisition explicitly requires multi-track capability, conduct multiple specialized interviews sequentially; define this as a planned exception that must be documented and approved.
- Decision within each specialized interview:
  - If the candidate fails the specialized interview: Application Rejected (terminal).
  - If the candidate passes the planned specialized track(s): proceed to Behavioral Interview.
- Synchronization J1:
  - If multiple specialized interviews were planned, all must be completed and passed before moving to Behavioral Interview.

5) Behavioral Interview
- Controlled re-interview policy:
  - Allow at most one additional Behavioral Interview (optional) only if a specific criterion is met (e.g., incomplete panel quorum). No open-ended looping.
- Decision G5 (exclusive):
  - If not suitable culturally/behaviorally: Application Rejected (terminal).

6) Background checks (deferred and staged)
