# IDEAL Process Model

## Process Overview and Purpose
The IDEAL process model represents an optimized, compliant, and efficient loan application and approval workflow. This target state process eliminates inefficiencies, standardizes procedures, and improves customer experience while maintaining regulatory compliance. The redesigned process focuses on early screening, clear decision criteria, reduced rework, and faster processing times.

## Key Stakeholders and Roles Involved
* **Customers/Applicants**: Individuals seeking loan approval
* **Digital Application Portal**: Automated initial screening and appointment scheduling
* **Loan Application Specialists**: Handle application intake and preliminary verification
* **Underwriting Team**: Standardized risk assessment and decision-making
* **Collateral Assessment Team**: Single, comprehensive property evaluation
* **Quality Assurance/Compliance**: Monitors process adherence and regulatory compliance
* **Customer Service Representatives**: Manages communication and status updates

## Detailed Step-by-Step Process Flow

### 1. Start Conditions and Triggers
* **Trigger**: Customer initiates loan inquiry through digital portal or branch visit
* **Entry Point**: "Submit Preliminary Application" activity
* **Initial Screening**: Automated eligibility check based on basic criteria

### 2. Digital Pre-Qualification Phase
* **Activity 1: Submit Preliminary Application**
  * Customer completes online pre-qualification form
  * Automated credit check (soft pull) performed
  * Basic eligibility criteria validated
  * **Decision Point**: Automated Pre-Qualification Check
    * **Outcome A (Immediate Denial)**: Clear ineligibility → Process terminates with explanation
    * **Outcome B (Proceed)**: Meets minimum criteria → Schedule appointment

* **Activity 2: Schedule Comprehensive Appointment**
  * System automatically suggests available time slots
  * Required documentation checklist provided
  * Confirmation sent via preferred communication channel
  * **Eliminated**: Manual appointment denial path (replaced by automated pre-qualification)

### 3. Application Submission and Verification Phase
* **Activity 3: Submit Complete Application**
  * Customer provides all required documentation
  * Digital document upload and verification
  * Application completeness automated check
  * **Standardized**: Single submission point with clear requirements

* **Activity 4: Comprehensive Verification**
  * **Consolidated Activity**: Single verification process replaces multiple paths
  * Automated data validation against external sources
  * Risk scoring algorithm applied
  * **Structured Decision Matrix**:
    * **Score ≥ 80**: Proceed directly to underwriting
    * **Score 60-79**: Additional requirements identified (co-signer OR collateral)
    * **Score < 60**: Application rejected with specific feedback
  * **Eliminated**: "skipped_examination" path (replaced by standardized scoring)

### 4. Additional Requirements Management (Structured Approach)

#### **Co-Signer Requirement Path**
* **Trigger**: Risk score indicates need for additional credit support
* **Activity: Request and Process Co-Signer**
  * Automated co-signer invitation system
  * Parallel processing of co-signer application
  * **Decision Rule**: Co-signer processed concurrently with main application
  * **Eliminated**: Sequential collateral assessment after co-signer request

#### **Collateral Assessment Path**
* **Trigger**: Risk score indicates need for asset verification
* **Activity: Conduct Comprehensive Collateral Assessment**
  * **Single Visit Protocol**: One comprehensive assessment replaces multiple visits
  * Standardized assessment checklist
  * Digital assessment tools for consistency
  * **Decision Rule**: Assessment completed within 48 hours, no rework loops
  * **Integration**: Assessment results feed directly into underwriting system

### 5. Underwriting and Decision Phase (Optimized)
* **Activity: Submit to Underwriting Queue**
  * Complete digital file assembly
  * Automated prioritization based on risk score and complexity
  * **Performance Target**: 24-hour underwriting turnaround for standard cases

* **Underwriting Decision Process**:
  * **Standardized Decision Framework**: Clear approval/denial criteria
  * **Automated Recommendations**: System suggests decision based on risk scoring
  * **Human Review**: Underwriter confirms or overrides with documented rationale
  * **Decision Outcomes**:
    * **Approval**: Proceed to finalization
    * **Conditional Approval**: Minor adjustments required
    * **Denial**: Specific reasons documented for regulatory compliance

### 6. Finalization and Closing Phase
* **Activity: Prepare and Sign Loan Agreement**
  * Automated document generation
  * Electronic signature capability
  * Funds transfer scheduling
  * **Target**: Same-day closing for approved applications

## Process End States (Streamlined)
1. **Early Rejection** (Automated pre-qualification): Immediate feedback to customer
2. **Application Rejected** (Structured verification): Specific improvement areas identified
3. **Loan Approved**: Successful completion with signed agreement
4. **Loan Denied**: Clear, documented reasons provided

## Process Metrics and Performance Targets
* **Target Approval Rate**: Increase from 23.9% to 40-45%
* **Processing Time Reduction**:
  * Direct approval path: Reduce from 94.3 hours to 48 hours
  * Complex paths: Reduce from 130.5 hours to 72 hours
* **Rework Elimination**: Zero consecutive collateral assessments
* **First-Time Quality**: 95% of applications processed without rework
* **Customer Satisfaction**: Target 90% satisfaction rate
