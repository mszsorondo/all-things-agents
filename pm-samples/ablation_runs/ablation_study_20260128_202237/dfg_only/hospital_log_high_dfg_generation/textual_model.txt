IDEAL Process Model

Process overview and purpose
- This target design streamlines the observed flow while preserving all legitimate clinical activities: Registration (FD/ER), Examination or Expert Examination with controlled escalation to Thorough Examination, Diagnosis, Treatment, explicit outcome classification (successful or unsuccessful), and Discharge.
- It removes or constrains wasteful and noncompliant behaviors (e.g., discharging after treatment without an explicit outcome) and clarifies decision logic to reduce escalations and rework.

Key stakeholders and roles involved
- Roles are not specified in the source. The process is described for the Patient and a generalized Healthcare provider team. Governance improvements are stated as rules within the existing activity set (no new activities introduced).

Detailed step-by-step process flow

Start conditions and triggers
- Start events:
  - Register at FD (primary care channel)
  - Register at ER (emergency channel)
- These remain separate start points but feed a single standardized triage logic.

Standardized post-registration triage (XOR)
- After registration, route to exactly one of:
  1) Examination (default pathway for routine/low-complexity presentations)
  2) Expert Examination (for clearly complex/specialized presentations)
  3) Thorough Examination (reserved for clearly critical/complex cases where comprehensive assessment is immediately warranted)
  4) Direct Diagnosis (fast-track only when clinical evidence is unequivocal)
- Improvements:
  - Formalize criteria for each route to minimize unnecessary escalations later. The choice is made once, based on available information at registration and initial assessment signals, and documented.

Assessment and escalation (controlled)
- Examination path:
  - Examination -> Diagnosis by default.
  - Conditional escalation to Thorough Examination only if Examination evidence is insufficient. Escalation is allowed once per case prior to the first Diagnosis.
- Expert Examination path:
  - Expert Examination -> Diagnosis by default.
  - Conditional escalation to Thorough Examination only if expert-level assessment still lacks sufficient evidence. Escalation is allowed once per case prior to the first Diagnosis.
- Thorough Examination path:
  - Thorough Examination -> Diagnosis (no further assessment escalation).
- Improvements:
  - Limit the number of escalations (at most one escalation to Thorough Examination before the first Diagnosis), reducing repeated waits and handoffs.
  - Make routing criteria explicit so that Thorough Examination is used intentionally rather than as a frequent fallback.

Diagnosis to treatment
- Diagnosis -> Treatment (required sequence; no shortcuts).
- Improvements:
  - Ensure completeness of diagnostic information before starting Treatment (especially if no prior Thorough Examination and diagnosis remains uncertain).

Treatment and mandatory outcome classification (XOR)
- From Treatment, exactly one of the following must occur:
  - Treatment successful -> Discharge
  - Treatment unsuccessful -> Diagnosis (rework)
- The direct path Treatment -> Discharge is removed. Discharge requires an explicit outcome classification step (successful vs unsuccessful).
- Improvements:
  - Data quality and compliance: All discharges reflect a documented treatment outcome.
  - Eliminate ambiguity and enable performance monitoring of treatment effectiveness.

Rework loop (constrained)
- If Treatment unsuccessful:
  - Return to Diagnosis.
  - If the prior pathway to Diagnosis did not include Thorough Examination and diagnostic uncertainty remains, proceed to Thorough Examination before re-diagnosing. Otherwise, proceed directly to Diagnosis.
- Improvements:
  - Use existing activities to prevent low-value cycling: require a comprehensive assessment (Thorough Examination) before repeating treatment when previous steps lacked it.

Decision points with criteria and outcomes
- Triage decision (XOR) with documented criteria to choose one of the four assessment entry paths.
- Assessment escalation (XOR) with a single-escation rule to Thorough Examination.
- Treatment outcome decision (XOR) mandates explicit outcome classification prior to Discharge.

Parallel activities and synchronization points
- No explicit parallelism is introduced, aligning with observed sequential flow. The design focuses on cleaner XOR logic and minimized escalations.

Exception handling and error paths
- Fast-track to Diagnosis remains permitted for clearly evident conditions; otherwise an assessment step is required.
- If a patient’s condition worsens or remains unresolved after an unsuccessful treatment:
  - Re-diagnose; if necessary, leverage Thorough Examination before repeating Treatment.
- Discharge without outcome classification is not allowed.

Rework loops and escalation procedures
- Rework loop exists only when Treatment unsuccessful, and is bounded by:
  - Mandatory reconsideration of diagnostic completeness (prefer Thorough Examination if not already performed and uncertainty persists).
  - Explicit documentation of outcome at each treatment cycle to track effectiveness and prevent silent cycling.

End conditions and outcomes
- Discharge (single end state), reachable only after “Treatment successful -> Discharge.”
- Cases may undergo one or more diagnosis-treatment cycles, but each cycle must end in either successful outcome and discharge, or further re-diagnosis with strengthened evidence.

Process metrics and performance characteristics (targets)
- Reduce escalations:
  - Expert/Examination -> Thorough Examination escalation rate target: <25% (from current ~63% and ~55% respectively).
- Eliminate direct Treatment -> Discharge hops:
  - 0% of discharges without explicit “Treatment successful.”
- Cycle time targets (median):
  - Registration to first assessment: ~6–8 hours (from ~11.1 hours)
  - Assessment to Diagnosis: ~8–10 hours (from ~16.7 hours)
  - Diagnosis to Treatment: ~8–10 hours (from ~16.7 hours)
  - Treatment to outcome classification: ~8–10 hours (from ~16.7 hours)
  - Outcome to Discharge: ~6–8 hours (from ~11.1 hours)
  - Dominant path end-to-end: ~48–60 hours (from ~88.9 hours), excluding rework.
- Rework:
  - Unsuccessful treatment loop rate target: <8% of treatments (from ~14.9%), achieved by improved initial triage and bounded escalation.

Improvements made (summary)
- Standardized triage: One-time, criteria-based routing to the appropriate assessment level; minimizes later escalations.
- Controlled escalation: At most one escalation to Thorough Examination before first Diagnosis; prevents repeated delays.
- Mandatory outcome classification: Removes ambiguous Treatment -> Discharge behavior; improves transparency and compliance.
- Rework governance using existing activities: Before repeating treatment after an unsuccessful outcome, ensure diagnostic completeness (prefer Thorough Examination if not previously performed and uncertainty persists).
- Performance focus: Tighter inter-step SLAs to reduce average waits by ~30–45% and shorten overall cycle time.
- Data quality and monitoring: Outcome documentation enables reliable effectiveness metrics and root-cause analysis of rework.
