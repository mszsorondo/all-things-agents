"""
IDEAL Process Model

Process overview and purpose
- Title: Standardized Hiring Flow — Application to Offer/Reject (Target/To-Be)
- Purpose: Provide a streamlined, auditable, and efficient hiring process that preserves necessary evaluation steps (screening, technical interviews, background checks, behavioral review) while removing redundant paths, eliminating unnecessary loops, enforcing gates and SLAs, and reducing coordination overhead through controlled parallelism.

Key stakeholders and roles (roles are clarified here to enable governance; these roles are implied by source activities and are explicitly assigned in the IDEAL model)
- Candidate — submits application.
- Recruiter (HR) — responsible for intake, scheduling, administering background checks, and moving candidate between stages.
- Hiring Manager — owner of hiring decision; approves progression to offer.
- Technical Interviewers / Technical Panel — run coding and domain/role-specific interviews (ML, Backend, Frontend).
- Behavioral Interviewer(s) / Panel — conducts behavioral assessment.
- Background Check Provider (internal HR or external vendor) — executes background and extensive background checks.

Detailed step-by-step process flow (start → end) — IDEAL standardized sequence
Start conditions and trigger
1. Start: Candidate "Hands In Job Application". Recruiter captures application into tracking system (mandatory first step).

Mandatory initial screening and gating
2. Telephonic Screening — mandatory short screening call conducted by Recruiter or designated screener within a defined SLA (e.g., within 48 hours of application). Decision:
   - If candidate fails basic eligibility -> Immediate Rejection (Application Rejected, logged with reason).
   - If candidate passes basic eligibility -> Proceed to consolidated evaluation stage.

Parallel but coordinated pre-technical activities (controlled concurrency)
3. Controlled parallel activities (triggered only for candidates who pass telephonic screening):
   - Background Check (basic) — Recruiter initiates automated basic checks in parallel.
   - Screening Interview — If job requires deeper initial screening, run a single screening interview. If not required, this step is explicitly skipped with documented reason.
   These two activities are designed to run concurrently but must both be complete before the candidate proceeds to the technical assessment stage (synchronization point).

Gate: Proceed to Technical Assessment only when:
   - Telephonic Screening passed
   - Basic Background Check completed with no disqualifying findings OR flagged for further review
   - Screening Interview (if required) completed

Technical evaluation: consolidated, scheduled and time-boxed
4. Consolidated Technical Assessment (reorganization of existing technical activities):
   - Execute Coding Interview plus role-specific technical evaluations (ML / Backend / Frontend) in a coordinated block to reduce scheduling overhead. Implementation options:
     - Panel session that covers coding + role-specific assessments OR
     - Two back-to-back technical interviews in one day.
   - Scheduling: Recruiter coordinates technical sessions to occur within a fixed SLA window (e.g., within 5 business days of clearance).
   - Outcome decision:
     - Fail technical assessment -> Application Rejected (documented).
     - Pass technical assessment -> Proceed to Behavioral Interview and (if required) an Extensive Background Check gating stage.

Behavioral interview and final background verification
5. Behavioral Interview (single step) — conducted by Hiring Manager or behavioral panel to evaluate fit and soft skills.
6. Extensive Background Check (conditional):
   - Only initiated for candidates who pass technical + behavioral assessments and are finalists for offer (reduce unnecessary extensive checks).
   - If extensive check fails -> Application Rejected with documented rationale.
   - If extensive check passes -> Proceed to decision.

Decision and Offer
7. Final Decision Gate (Hiring Manager + Recruiter):
   - Consolidate evaluation results from Telephonic Screening, Screening Interview, Technical Assessment, Behavioral Interview, and Background Checks.
   - If Hiring Manager approves -> "Make Job Offer" (visible action) executed by Recruiter; offer details and approvals logged.
   - If decision is not to hire -> "Application Rejected" with documented reason.

End conditions
- Successful completion: "Make Job Offer" → administrative close-out (onboarding tasks handled outside this hiring workflow).
- Negative completion: "Application Rejected" → candidate status updated and closed with reason code.

Exception handling, rework loops and escalation (controlled)
- Eliminate ad-hoc loops: Rework iterations (re-running interviews/checks) are restricted. If additional evaluation is needed, require explicit approval from Hiring Manager and Recruiter and a documented rationale; such rework is timeboxed (e.g., 3 business days).
- Escalation rule: If any step exceeds SLA (e.g., telephonic screening >48h, technical scheduling >5 days, background check >7 days), case is escalated to Recruiter Lead for remediation.
- Disqualification rules: Background-check failures or hard eligibility failures immediately route to rejection with automated notices.

Process metrics and target performance characteristics (IDEAL)
- Time-to-first-screen: Target ≤ 48 hours from application.
- Time-to-technical-assessment: Target ≤ 5 business days after screening pass.
- Time-to-final-decision: Target ≤ 2 business days after behavioral interview and background checks (or within defined vendor check SLA).
- Reduced variability: Eliminate optional ad-hoc skips — all steps follow documented gating rules.
- Throughput reduction for candidate cycle time: Aim to reduce average time-to-offer by eliminating repeated scheduling and consolidating technical interviews into single coordinated sessions.
- Quality metrics: % of candidates with completed background checks before offer; interviewer satisfaction; hiring manager decision rate within SLA.

Improvements made (how AS-IS issues are addressed)
- Standardized flow: Enforce mandatory gating (telephonic screening, basic background check), remove ambiguous silent routes by making decision points explicit and documented.
- Controlled concurrency: Keep parallel activities where useful (background check + screening interview) but require synchronization before moving to technical stage to reduce downstream variability.
- Consolidated technical evaluation: Reduce scheduling overhead and waiting time by coordinating technical interviews as a single block or panel.
- Limit expensive checks: Run Extensive Background Checks only for finalists to reduce wasted time and cost.
- Eliminate unnecessary loops: Require documented and approved rework to prevent repeated cycles without governance.
- Introduce SLAs and escalation: Measured SLAs reduce long waits and create accountability for delays.
- Make decision logic explicit: Replace many silent/implicit skip transitions with clear decision criteria and recorded outcomes for auditability and analytics.

Role/responsibility summary (IDEAL)
- Recruiter: intake, initial screening, schedule coordination, background check orchestration, offer issuance.
- Hiring Manager: technical/behavioral input, final decision authority.
- Technical Panel: conduct technical assessments in coordinated manner.
- Background Check Provider: execute basic and extensive checks per gating rules.

Validation and transition notes
- Transitioning from AS-IS to IDEAL requires:
  - Defining formal policies for which steps are mandatory vs optional.
  - Implementing scheduling coordination tools (to support consolidated technical blocks).
  - Configuring the ATS/HRIS to enforce gates, SLAs, and record reasons for skips/rework.
  - Training recruiters and hiring managers to follow the new gated approach and escalation rules.

Summary (IDEAL)
- The IDEAL model keeps all necessary evaluation activities from the discovered net (screening, coding and role-specific technical assessments, behavioral interview, background checks) but places them in a controlled, auditable, and efficient sequence: mandatory telephonic screening → parallel but synchronized screening/background → consolidated technical assessment → behavioral interview → gated extensive check for finalists → hire or reject. This reduces variability, removes ad-hoc loops, enforces SLAs, and improves candidate experience and time-to-hire.
"""
