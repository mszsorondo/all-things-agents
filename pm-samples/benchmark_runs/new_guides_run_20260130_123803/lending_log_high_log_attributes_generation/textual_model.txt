IDEAL Process Model

Process overview and purpose
- Purpose: A controlled, auditable, and efficient credit application process that applies consistent criteria, ensures necessary checks are completed, and minimizes unnecessary rework while preserving all legitimate decision paths.
- Improvement priorities: Standardize decisioning, enforce gating controls, streamline intake, and formalize conditional handling for co-signers and collateral.

Key stakeholders and roles involved (unchanged, but with clarified responsibilities)
- Online System: Executes and records initial request and verification activities where possible.
- Hotline: Handles phone-based requests and communicates screening outcomes.
- Loan Officers 1–5: Own intake verification, appointment management, and application completeness checks.
- Resource 1–5: Perform operational tasks including collateral visits and file preparation.
- Underwriters: Chill UW1–UW3, Strict UW1–UW3, MostChillUW; allocation policy clarified to ensure consistent criteria and auditability.

Detailed step-by-step process flow

Start conditions and triggers
- Trigger: Borrower initiates a Request Appointment via Online System or Hotline.
- Start activity: Request Appointment.

Stage 1: Pre-appointment screening (tightened sequencing)
- Verify Borrowers Information must complete before any appointment is confirmed.
  - Decision: Appointment eligibility
    - If Not Eligible: Appointment Denied → End.
    - If Eligible: Proceed to appointment scheduling.

Stage 2: Appointment logistics and application intake
- Set Appointment: Schedule only after verification passes to reduce avoidable denials.
- Hand In Credit Appliaction: Collect complete documentation at or immediately after the appointment.
- Decision: Intake completeness/eligibility
  - If Not Complete/Not Eligible: Application Rejected → End.
  - If Complete/Eligible: Proceed to underwriting preparation.

Stage 3: Underwriting preparation and conditional checks
- Inclusive decision: Collateral needed?
  - If Yes: Make Visit to Assess Colatteral must be performed and recorded before underwriting decisioning.
  - If No: Skip this activity explicitly by rule (no implicit auto-skip events).
- Synchronization point: All required intake artifacts (application and, if required, collateral visit) must be complete before the underwriting handoff.

Stage 4: Underwriting handoff and decisioning (standardized and fully logged)
- Mandatory handoff event: Submit File to Underwriter recorded for every case that reaches decisioning. The skipped_examination path is removed.
- Underwriter allocation policy:

  - Final negative: Loan Denied → End.
  - Final positive: Sign Loan Agreement → End.

Parallel activities and synchronization points

Exception handling and error paths

- Negative ends:
